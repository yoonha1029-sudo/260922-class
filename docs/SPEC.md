# 사이트 설계 명세 초안

## 목적과 범위

학생이 태블릿이나 스마트폰에서 학년·단원별 과학 학습 자료를 열람하는 정적 웹사이트다. 교사는 HTML, Markdown, JSON, PDF 파일을 직접 수정해 운영한다. 서버, 데이터베이스, 로그인, 회원가입, 제출, 댓글 기능은 범위에 포함하지 않는다.

## 메뉴와 화면

- 공통 상단 메뉴: 홈, 2학년, 3학년
- 홈: 학년 선택 카드, 최근 수정 자료 목록
- 학년 화면: 해당 학년 단원 카드 목록
- 단원 화면: 공통 `unit.html` 템플릿에 `id` URL 매개변수로 단원 표시
- 공통 하단: 자료 마지막 수정일

## 단원 데이터와 표시 영역

단원 정보는 `data/units.json`의 `units` 배열 하나로 관리한다.

### 단원 필드
`id`, `grade`, `order`, `title`, `updated`, `worksheets`, `virtualLabs`, `resources` 만 사용한다.
단원 소개, 핵심 개념, 수업 순서는 두지 않는다.

### 자료 분류 (화면 표시 순서)
1. 학습지 (`worksheets`): `file` 사용. `content/` 아래 상대경로의 PDF. 카드마다 PDF 미리보기, 새 창 열기, 다운로드 버튼을 둔다.
2. 가상실험 (`virtualLabs`): `url` 사용. 시뮬레이션 등 외부 링크. 새 탭 열기 버튼.
3. 관련 자료 (`resources`): `url` 또는 `file` 사용. 영상, 복습 자료 등 나머지 전부.

### 카드 규칙
- 카드의 필수 항목은 `title`과 `file` 또는 `url`이다.
- `description`은 선택 항목이다. 있으면 제목 아래에 작은 글씨 한 줄로 표시하고, 없으면 아무것도 표시하지 않는다.
- 분류당 카드 개수는 제한하지 않는다. 카드는 간결하게 표시한다.

### 표시 규칙
- 세 분류는 서로 독립적이다. 어떤 분류든 단독으로, 또는 함께 올릴 수 있다.
- 배열이 비었거나 없는 분류는 화면에서 숨긴다.
- 세 분류가 모두 비어 있으면 "자료 준비 중" 안내만 표시한다.
- PDF 파일이 없으면 "미등록" 안내만 표시하고 미리보기는 만들지 않는다.
- 외부 링크는 항상 새 탭에서 연다.

## 시각·접근성 원칙

흰 배경, 차분한 진초록 한 가지 포인트, 얇은 카드 테두리와 간결한 여백을 사용한다. 작은 화면에 단일 열로 재배치하며 링크와 버튼은 터치하기 쉬운 최소 높이를 갖는다. 키보드 초점 표시와 본문 바로가기 링크를 둔다. 기본 시스템 글꼴을 사용한다.

## 개인정보와 검색 노출

학생 개인정보를 수집·저장하지 않는다. 분석·추적·외부 폼을 사용하지 않는다. 각 HTML에 `noindex` 메타 태그를 두고 `robots.txt`에서 수집을 금지한다. 이 설정은 비밀번호나 접근 통제 기능이 아니다. 배포 주소를 아는 사람은 접속할 수 있다.

## 배포·로컬 확인

빌드 단계 없이 저장소 루트를 Netlify 또는 Vercel에 배포한다. JSON `fetch()` 동작을 위해 로컬에서는 정적 HTTP 서버를 사용한다. 구체적인 절차는 `README.md`와 `DEPLOY.md`를 참고한다.
