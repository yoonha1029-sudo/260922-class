# 배포와 공개 범위 안내

## GitHub와 Netlify/Vercel 배포

1. 사이트 파일을 GitHub 저장소에 올립니다.
2. Netlify 또는 Vercel에서 해당 저장소를 연결합니다.
3. 빌드 명령은 비워 두고, 게시 디렉터리를 저장소 루트(`/`)로 지정합니다.
4. 배포 후 홈, 학년 목록, 단원 상세, PDF 링크가 동작하는지 확인합니다.
5. JSON이나 자료를 바꾼 뒤 GitHub에 반영하면 연결된 호스팅이 정적 파일을 다시 배포합니다.

이 사이트는 순수 정적 파일이라 서버 코드나 별도 빌드 설정이 필요하지 않습니다.

## 검색 수집과 실제 접근 제한

HTML의 `noindex` 메타 태그와 `robots.txt`는 검색 엔진에 수집하지 말라고 알리는 설정입니다. 검색 엔진이 이를 따르도록 요청할 뿐, 페이지를 보호하지 않습니다. 기본 배포 주소만으로는 완전한 비공개가 아닙니다. 주소를 아는 사람은 누구나 접속할 수 있으므로 민감하거나 개인정보가 있는 자료를 올리지 마세요.

접근 제한이 필요하면 호스팅의 학교 계정 제한, 비밀번호 보호, 별도 인증 서비스 연동을 검토하세요. 제공 방식과 이용 조건은 선택한 호스팅 서비스의 현재 안내를 확인해야 합니다.
